蓝渐变替代方案 — 3 个方向

当前方案使用 #4a6cd9 → #4a3fe0 → #5562f5 的蓝紫渐变。即使收敛后，亮度仍会把视线从内容上拉走。下面是 3 个降低注意力消耗的方向，每个方向都展示同一组关键品牌界面：侧栏 logo、主操作按钮、用户头像、轻强调横幅。

CURRENT
TOMS 蓝紫渐变 — 视觉抢眼，但在中性灰底上偏跳脱。
A · 石墨单色

SOLID GRAPHITE

完全去掉渐变与彩色，全部品牌面用近黑灰。最克制，让内容（KPI、状态、表格）成为页面唯一的颜色发声方。

优点

  • 视觉噪音最低
  • 把彩色让给状态色（成功/警告/危险）
  • 打印 / 截屏 / 黑白都好看

取舍

  • 品牌识别度变弱，TOMS 不再"有色彩"
  • 主按钮和次按钮对比仅靠明度
B · 中性品牌 + 单色靛蓝 CTA

NEUTRAL BRAND, SOLID CTA

Logo / 头像变中性灰，但 主操作按钮保留单色靛蓝（去掉渐变）。让"重点放在用户该点的地方"，而不是 logo 上。

优点

  • 主 CTA 仍清晰可点，强调按钮而非 logo
  • 渐变完全去掉，不再"亮"
  • 和 Linear / Vercel / Notion 视觉语言一致

取舍

  • 品牌色"声量"减少 ~70%
  • 页面上品牌色只剩按钮一处
C · 哑光深紫渐变

MUTED DUSK GRADIENT

保留渐变的"运动感"，但大幅降低饱和度和明度。从亮蓝→紫，改为深紫→灰紫，类似哑光金属。仍然有渐变，但不再"发光"。

优点

  • 保留品牌的"渐变 DNA"
  • 不再亮蓝、不再抢镜
  • 暗色模式天然适配

取舍

  • 仍是"花活"，不如 A/B 克制
  • 低饱和度小尺寸下接近纯黑
我的建议：B（中性品牌 + 单色靛蓝 CTA）。它是最稳的工程化路径 —— logo 安静、CTA 仍然能引导用户、渐变彻底去掉，不会再"发光"。如果还是希望保留品牌的渐变质感，C 是最优雅的折中。A 适合你打算把整个产品向"无色"系统（如金融 / 政府 / 极简工具）靠拢的场景。
